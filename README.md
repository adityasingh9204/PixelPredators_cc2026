# Royal Rajasthani Kathputli Show

A cinematic p5.js animation inspired by traditional Rajasthani puppet theatre.

## Features

- Animated Kathputli puppets
- Royal theatre stage
- Dynamic curtains
- Floating lanterns
- Interactive confetti
- Traditional Indian aesthetic

## Controls

- SPACE → Skip intro
- R → Restart show
- Mouse Click → Confetti burst

## Technologies

- p5.js
- HTML5 Canvas
- JavaScript
- CSS3

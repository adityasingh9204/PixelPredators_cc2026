#  Royal Rajasthani Kathputli Show

An immersive and cinematic p5.js animation inspired by the traditional Kathputli puppet theatre of Rajasthan, India. This project recreates the vibrant atmosphere of a royal folk performance using animated puppets, dramatic curtains, glowing lanterns, audience reactions, and celebratory visual effects.

The animation highlights the beauty of Indian culture and heritage through smooth transitions, synchronized puppet dance movements, handcrafted stage design, and interactive storytelling elements.

---

##  Features

- Royal Rajasthani theatre stage
- Traditional Kathputli puppet animation
- Dynamic opening curtains
- Smooth puppet dance performance
- Floating lantern lighting effects
- Animated audience silhouettes
- Interactive confetti celebration
- Responsive fullscreen canvas
- Cinematic visual presentation

---

##  Controls

- SPACE → Skip intro
- R → Restart show
- Mouse Click → Confetti burst

---

## Technologies Used

- p5.js
- JavaScript
- HTML5 Canvas
- CSS3

## 🇮🇳 Cultural Inspiration

Kathputli is a traditional string puppet art form native to Rajasthan, India. It is one of the oldest forms of folk entertainment in Indian culture and is known for its colorful costumes, expressive dance movements, and musical storytelling performances.

This project is a digital tribute to the rich artistic heritage of Rajasthan and aims to blend traditional Indian culture with modern creative coding techniques.

---

##  Project Goal

The goal of this project is to present Indian tradition and folk art in a visually engaging and interactive way suitable for hackathons, exhibitions, and creative coding showcases.
